# Surafel Sanga — GitHub Pages Portfolio

A responsive, dark-themed developer portfolio built with plain HTML, CSS, and JavaScript.

## Deploy to GitHub Pages

1. Create a GitHub repository, for example `surafelsanga.github.io`.
2. Upload `index.html`, `style.css`, and `script.js` (and the `assets` folder if you add images).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save. GitHub will publish the site at your Pages URL.

## Customize

- Update the GitHub and LinkedIn URLs in `index.html`.
- Replace the project descriptions and links.
- Add a real CV link to the **Download My CV** button.
- Replace the CSS-generated project artwork with screenshots in `assets/` when you have them.
- Update the experience dates/details to match your final CV.

No build step or framework is required.
